Sales Performance Analysis

An end-to-end data analytics project where the same sales dataset was analyzed using Excel, SQL, Python, and Tableau to extract meaningful business insights related to sales trends, regional performance, and product contribution.

Problem Statement

Businesses need a clear understanding of their sales performance across regions, products, categories, and time periods to make informed decisions. This project analyzes sales data to identify trends and key performance drivers.

Tools & Technologies

  • Excel – Formulas, Pivot Tables, Charts
  • SQL (MySQL) – Aggregations, Filtering
  • Python – Pandas & Matplotlib
  • Tableau – Interactive Dashboard

Excel Analysis

Excel was used for initial data exploration, revenue calculations, pivot table analysis, and visualization.

  • Region-wise revenue analysis
  • Monthly sales trend analysis
  • Product-wise revenue comparison
  • Category-wise revenue contribution
