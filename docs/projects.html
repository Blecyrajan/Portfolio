Sales Performance Analysis

This project analyzes sales data to understand revenue distribution, monthly trends, product performance, and regional sales behavior. The objective is to generate insights that support business decision-making.

Tools Used

  • Excel – Data cleaning and summaries
  • Python – Data analysis and visualization
  • Matplotlib – Charts and plots

Key Insights

  • Electronics category generated the highest revenue
  • Sales showed noticeable monthly variation
  • Regional revenue performance varied significantly

QuickList – Task Management System (MERN)

QuickList is a full-stack task management web application developed using the MERN stack. The application allows users to create, update, complete, and delete tasks with persistent storage using MongoDB.

Tech Stack

  • Frontend: React, CSS
  • Backend: Node.js, Express.js
  • Database: MongoDB
  • API Communication: Axios

Features

  • Add new tasks
  • Edit existing tasks
  • Mark tasks as completed
  • Delete tasks
  • RESTful API integration

What I Learned

  • Building REST APIs using Express
  • CRUD operations with MongoDB
  • Connecting frontend and backend using Axios
  • Managing state and UI updates in React
